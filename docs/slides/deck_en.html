How it was measured

Webiks: their training code's validation split. Clean: 150 pages with no question in the QA file, one question each, written with the title hidden from the writer. Public: the 300 questions a competitor published. My evaluator matches Webiks' to 4 decimals.

Per question

Webiks: 114 better, 47 worse; top 3 from 58% to 65%. Clean: 38 vs 19. On the public set the difference is noise: the title helps when a question names the population or sub-case.

Tested and switched off: a separate title vector at 0.3

53% on the Webiks set, but it gave the gain back on both independent sets. Off, kept as an option.

LLM factory: any model you want

OpenAIAzureOllamavLLMAnthropicGemini+ your own
One interface: messages in, text out. A new model is a small class registered by name.
Off by default. To turn on, in app/.env:
TITLE_RERANK_ENABLED=true
TITLE_RERANK_PROVIDER=openai
TITLE_RERANK_MODEL=gpt-4o-mini
On any failure it falls back to the plain order. Cost: ~0.8 s per query and an LLM key; no effect in mock mode. Hence off.
